Things that I learned in Introduction to CSS

In module three, I learned that there's three ways to apply CSS to any HTML. These ways are inline - using the style attribute inside HTML elements, internal - using the < style > element inside in the head section, & external, which is the most common and is used by using a < link > element to link to an external CSS file. I also learned a CSS Rule is broken down into various diffrent parts:

  1. Selector - What you're styling
  2. Statement - a Property-Value pair
  3. Property - Changing of the Element
  4. Value - Setting you're chaning the property to
  5. Rule - The Selector & Statement with at least one Property-Value pair

Fonts Colors Size Etc

There are many values you can change within CSS to customize the appearance of you website. Some of them are color, font-family, font-size, border, padding & margin.

Class & ID Selectors

Both class & ID selectors can be used to style specific information, such as the "Reflection on Module..." & Dan939342 in bold at the bottom. w3schools was particularly helpful in helping me understand this concept.

Things that I learned in Section 6 - HTML Notes

HTML tags are the carrots or greater than & less than signs on the keyboard. HTML Tags Should be lowercase. They can be nested, & also can have attributes. Attributes define a setting for a tag. Some settings are Unique Identifier (id), context (class), title as a tooltip (title) & apply inline style sheet rules (style).
