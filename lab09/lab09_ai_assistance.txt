- **The page must be served over HTTP.** If you open the HTML file directly from disk (`file://`), most browsers block the XHR request for `employee.xml`. Run it through a local server, such as `python -m http.server` or the VS Code Live Server extension.

- **`responseXML` can be null.** If the server sends the file with a non-XML content type, `xmlDoc` will be null. Calling `xmlhttp.overrideMimeType("text/xml")` before `send()` avoids this.
